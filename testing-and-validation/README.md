# NeuroSynIQ — Testing and Validation

This folder contains the testing and validation evidence for NeuroSynIQ, developed for the Science Fair 2026 Innovation Category.

The evidence includes:
- Real tablet tapping experiments.
- A 100-case simulated evaluation of PersistenceGuard.
- Comparison of a simple threshold method and PersistenceGuard.
- Experimental findings, limitations, and conclusions.

NeuroSynIQ is a research prototype and does not diagnose neurological conditions or replace medical professionals.
